# raw：記録層

事実の原本を保存する場所です。記録は追記のみとし、既存の内容を書き換えたり削除したりしません。訂正は元の記録を残して追記します。

| 場所 | 内容 | 命名 |
| --- | --- | --- |
| `conversations/` | 会話の記録 | `YYYY-MM-DD_トピック.md` |
| `decisions/` | 判断とその根拠 | `NNNN-決定内容.md`（連番） |
| `issues/` | Issue と関連記録 | `YYYY-MM-DD_番号/` |

この層を根拠として `wiki/pages/` に知識を蒸留します。大きな原本の扱いは `wiki/SCHEMA.md` を参照してください。
