# 開発スキルと記録先

- 日付: 2026-11-13
- 対象: `game-poc` の開発フロー、Matt Pocock 系スキル、Issue tracker、ローカル Wiki
- 確認した事実: リポジトリは GitHub `bundai223/game-poc` を remote に持つ。`to-spec`、`to-tickets`、`implement`、`code-review`、`triage` スキルが利用可能。Issue ごとの記録を `raw/issues/` に置き、`wiki/pages/` に根拠付きで蒸留する運用がある。リポジトリ内に TSV ファイルは見つからなかった。
- 判断: GitHub Issues を作業の受付・状態管理に使い、ローカル `raw/issues/` を Issue ごとの事実・判断・検証記録、`wiki/pages/` を長期的な知識の記録先として併用する。Issue の計画・作成、指定 Issue の実装、差分の報告・レビューを分け、マージ報告だけで次の実装に進まない。TSV の役割は既存リポジトリから確認できないため設定に含めない。
- ラベル: triage の標準名 `needs-triage`、`needs-info`、`ready-for-agent`、`ready-for-human`、`wontfix` を使用する。GitHub には `wontfix` が既にあり、他の4件を追加する。
- 検証結果: `git remote -v`、スキル配置、既存 Wiki、GitHub ラベルを確認した。Wiki の構造は `wiki/SCHEMA.md`、運用ページは `wiki/pages/infrastructure/Issue単位の開発運用.md` を参照。
- 未解決事項: 「TSV ファイル」がこのリポジトリ外の記録を指す場合、そのファイルと役割は未確認。
- 関連ファイル: `AGENTS.md`、`docs/agents/`、`wiki/pages/infrastructure/Issue単位の開発運用.md`
