# Web エクスポートの検証

日付: 2026-11-04
対象: Web プレビューの先行検証（#17、#18）

- Godot 4.7.2 の Web プリセットに Compatibility、シングルスレッド、拡張なしの設定を使用し、`make export-web` で `build/web/index.html` と関連ファイルを出力した。
- ローカル HTTP サーバー経由のブラウザ画面で「Draw Physics PoC - setup complete」を確認した。
- ユーザーは Tailscale 限定共有を選択した。既存の共有設定を残し、別ポートでローカルサーバーを共有した。Mac 自身から共有 URL の HTML と WebAssembly に HTTP 200 が返り、WebAssembly の MIME type が `application/wasm` であることを確認した。
- リモート端末での接続、タッチ操作、性能は未確認。実装は最小シーンで、お絵描き機能はまだない。
- 関連: `export_presets.cfg`, `Makefile`, `README.md`。
