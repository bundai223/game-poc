# Issue #45: 図形の移動

- 日付: 2026-11-12
- 対象: 2D Draw の Move モード
- マウスまたは1本指で図形のつかんだ位置を保って移動する。空白から開始した場合は移動しない。重なりは最後に生成された図形を選ぶ。
- 移動中は対象を固定して直接位置を変えるため、障害物をすり抜ける。終了時は並進・回転速度ゼロで物理を再開する。キャンセル、フォーカス喪失、モード切替、Reset でも操作を解除する。
- `make test` は 52 件成功。Web 出力後の Chromium E2E は既存操作の 4 件が成功。移動操作のブラウザ E2E と実機は未確認。
