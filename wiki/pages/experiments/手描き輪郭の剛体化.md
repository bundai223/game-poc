# 手描き輪郭の剛体化

## 目的

マウスまたは1本指で描いた輪郭を `RigidBody2D` に変え、床への落下と衝突を試す。

## データと制約

`outline.gd` は `PackedVector2Array` を受け取り、簡略化後の点列または空配列を返す。面積500平方ピクセル以上、3〜32頂点の単純な輪郭を受け付ける。非有限座標、自己交差など不正な輪郭は拒否する。凹形状は `CollisionPolygon2D` の既定の `BUILD_SOLIDS` により凸分解される。輪郭処理は Node に依存しない。

`main.gd` はドラッグ中に輪郭を描き、リリース時に検証する。`Polygon2D` と `CollisionPolygon2D` は同じ局所座標を使う。表示用ポリゴンの外周には黒い閉じた線を描き、切断後の破片にも適用する。画面のモードボタンは Draw、Cut、Delete、Connect、Move の順に切り替わる。削除モードでは、タッチまたはクリックした位置の衝突判定により図形を1個削除できる。重なった図形の選択順序は指定しない。Reset ボタンまたは `R` キーで生成した剛体をすべて消せる。

切断モードではドラッグ開始時に剛体を停止し、低速、静止、または一定以上の方向変化を検出した地点を折れ点として線をつなぐ。入力を離すと線で分割し、物理を再開する。凹形状や複数物体を切断できる。自己交差する線、既存の輪郭検証を通らない小片、面積が維持できない分割では元の物体を残す。

移動モードではマウスまたは1本指で図形をつかんだ位置を保って動かす。重なりは最後に生成された図形を選ぶ。移動中は障害物をすり抜け、終了時は速度ゼロで物理を再開する。連結済み図形は移動できず、接続を維持する。

地面の表示線と衝突面は、起動時のViewport高さから床の厚みを引いたY座標に置く。起動後のウィンドウサイズや画面向きの変更には追従しない。

## 検証

GdUnit4 の CLI で形状検証、マウスとタッチ入力のシーン統合、入力中断、固定物理ステップの落下・床接触を確認した。Mac の Chromium では Playwright で Web 版の読み込み、マウス描画、R キーによる消去を確認した。利用者は Android での操作と Reset に問題がないと報告した。機種、ブラウザ、フレームレートは未記録。iPad の実機操作は未確認。

2026-11-08、利用者は iPad で描画できないと報告した。修正前の入力処理はタッチ接触IDが `0` の場合だけ開始イベントを受け付けていた。Chromium のタッチ模擬では ID `0` で描画され、ID `1` と `7` では描画されなかった。開始した指のIDを追跡する修正と回帰テストを追加し、GdUnit4 15件と Playwright のマウス・タッチE2E 2件が成功した。修正後の iPad Safari 実機は未確認。

2026-11-12、利用者から、意図しない凹形状で物体が生成されないと報告があった。原因は輪郭検証が凹形状を拒否することだったため、この判定を外し、自己交差等の検証は維持した。凹形状の単体・入力統合テストを追加し、`make test` 21件すべて成功。実機の描画確認は未実施。
