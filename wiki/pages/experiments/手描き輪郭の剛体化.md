# 手描き輪郭の剛体化

## 目的

マウスまたは1本指で描いた輪郭を `RigidBody2D` に変え、床への落下と衝突を試す。

## データと制約

`outline.gd` は `PackedVector2Array` を受け取り、簡略化後の点列または空配列を返す。面積500平方ピクセル以上、3〜32頂点の凸輪郭を受け付ける。非有限座標、自己交差、凹形状を拒否する。輪郭処理は Node に依存しない。

`main.gd` はドラッグ中に輪郭を描き、リリース時に検証する。`Polygon2D` と `CollisionPolygon2D` は同じ局所座標を使う。画面の Reset ボタンまたは `R` キーで生成した剛体を消せる。

地面の表示線と衝突面は、起動時のViewport高さから床の厚みを引いたY座標に置く。起動後のウィンドウサイズや画面向きの変更には追従しない。

## 検証

GdUnit4 の CLI で形状検証、マウスとタッチ入力のシーン統合、入力中断、固定物理ステップの落下・床接触を確認した。Mac の Chromium では Playwright で Web 版の読み込み、マウス描画、R キーによる消去を確認した。利用者は Android での操作と Reset に問題がないと報告した。機種、ブラウザ、フレームレートは未記録。iPad の実機操作は未確認。

2026-11-08、利用者は iPad で描画できないと報告した。修正前の入力処理はタッチ接触IDが `0` の場合だけ開始イベントを受け付けていた。Chromium のタッチ模擬では ID `0` で描画され、ID `1` と `7` では描画されなかった。開始した指のIDを追跡する修正と回帰テストを追加し、GdUnit4 15件と Playwright のマウス・タッチE2E 2件が成功した。修正後の iPad Safari 実機は未確認。
